# Content fixtures

SAMPLE project and post YAML files live alongside real collections in `content/projects` and `content/posts`, marked with `sample: true` and names/titles prefixed with `SAMPLE`.

They exist so layout patterns, CMS field mapping, draft exclusion, and ordering can be verified without inventing portfolio achievements. Remove or unpublish them when real content replaces the demonstration.

Original SAMPLE photos are under `content/media/originals/sample-*.jpg`. Public derivatives are generated into `public/media/` during `npm run build`.
